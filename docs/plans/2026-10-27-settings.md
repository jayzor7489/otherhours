# World Clock Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every World Clock setting into the menu bar app (a Settings window with city search, slots, themes, time format), make the widget display-only, and have own time follow the Mac's time zone at once.

**Architecture:** Settings live in the app's own preferences (`com.jasonaldemita.worldclock`) as plist values; the sandboxed widget reads them through a `shared-preference.read-only` entitlement and the app calls `reloadAllTimelines()` after every change. Pure logic (stored settings, search, clock grouping, zone labels, layout caps) goes in `WorldClockCore` with tests; themes are SwiftUI views in `WorldClockViews`, shared by widget, panel, Settings previews and `WorldClockPreview`. The widget becomes a `StaticConfiguration`, which deletes the App Intents metadata hack.

**Tech Stack:** Swift 6 toolchain in Swift 5 mode, SwiftUI, AppKit, WidgetKit, Swift Testing, Python 3 for data scripts, Command Line Tools only.

**Spec:** `docs/specs/2026-10-27-settings-design.md` (read it first). Earlier design: `docs/specs/2026-10-27-world-clock-design.md`. Theme looks: `docs/mockups/visual-style.html` (A = List, B = Day & Night, C = Clocks, D = Spotlight).

## Global Constraints

- Everything from the first plan's Global Constraints still holds (`docs/plans/2026-10-27-world-clock.md`): `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk`, tests via `scripts/test.sh`, tools 6.0 / macOS 14 / Swift 5 mode, `_NSExtensionMain` link flags, ad-hoc signing (appex first), absolute install path `~/Applications`, bundle ids, widget kind `WorldClock`, U+2212 minus, no em/en dashes in copy, GeoNames credit, commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, never push.
- Preferences domain: `com.jasonaldemita.worldclock`. Keys: `cities` (array of dictionaries with string keys `name`, `countryCode` (optional), `timeZoneID`), `theme` (`dayNight` | `list` | `clocks` | `spotlight`, default `dayNight`), `hourCycle` (`system` | `h12` | `h24`, default `system`).
- Widget entitlement: `com.apple.security.temporary-exception.shared-preference.read-only` = `["com.jasonaldemita.worldclock"]`, alongside `com.apple.security.app-sandbox`.
- Search: at most 8 suggestions; one suggestion per distinct clock; the stored identifier of a grouped pick is the group's most populous identifier.
- Clock grouping rule: same UTC offset now and the same offsets at every transition over the next 12 months (spec "Finding cities").
- Layout caps (rows include own time): Day & Night and List as today (medium 3 full / 5 compact, large 7 / 10); Clocks medium 4, large 9; Spotlight medium 4, large 10. Over the cap: cap − 1 rows plus "+N more".
- Copy: footer button `Settings…`; empty panel row `Add cities in Settings`; empty widget note `Add cities from the menu bar 🌐`; no-result line `No place called '<text>'. Try a city, state or country.`; own row in Settings `<flag> <name> · your Mac's time zone`; theme names `Day & Night`, `List`, `Clocks`, `Spotlight`; time format options `Follow Mac`, `12-hour`, `24-hour`.

## Review Focus

1. **A saved zone that no longer exists** (identifier renamed or removed in a macOS update). Expect the row to be skipped, never a crash or a blank row. Test in Task 1.
2. **A change that never reaches the widget.** Every settings mutation must save and fire the change hook once. Tests in Task 1 (store), manual check in Task 9.
3. **Empty, whitespace or one-letter search text.** Empty/whitespace → no suggestions and no "No place" line; one letter → prefix matches, capped at 8. Tests in Task 5.
4. **A Mac zone missing from the city data** (`UTC`, `Antarctica/Troll`). Own row still shows, with 🌐 and a name from the identifier. Test in Task 1.
5. **Explicit time format against the Mac's locale.** `h24` on an en_US Mac gives `14:10` with no AM/PM; `h12` on en_GB gives `2:10` with a period. Test in Task 1.
